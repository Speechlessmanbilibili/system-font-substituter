# v2.1.6 第四轮性能优化

记录日期：2026-10-06，北京时间。基线为第三轮 2.1.6 测试构建的源码快照，保存于 `round4-before/`。测量使用本地模拟页面和独立 Chromium 测试浏览器。

## 实现

- 按语法位置分析字体选择器依赖，区分属性运算符、引号内容、转义标点与真实关系或状态条件。保留函数内的实际选择器和转义名称依赖，避免静态属性中的“~”导致菜单销毁时整页重检。
- 对单个转义或非 ASCII 类名、ID 按解码后的名称精确索引，省去逐元素匹配。复合选择器及怪异模式继续交给浏览器判断。
- 没有字体声明及字体变量的内联布局样式直接过滤，省去临时元素创建和 CSS 解析。字体声明的新增或删除、注释、转义及变量变化继续完整比较。
- 强制站点在非空自定义 CSS 接管、保留原生连字且关闭图标保护时直接应用标记，省去原字体采样。代码和图形保护保持生效；图标保护、连字或 CSS 模式改变后恢复所需的原样式读取。

用户 CSS 正文、Apple UI Mix 模板及 `shared.js` 保持原样。基线快照统一了换行，将 CRLF 统一为 LF 后，共有配置及 CSS 与工作区完全相同。

## 回归与测量

95 项自动回归通过，覆盖真实 MV3、隔离脚本、跨域 CSS、子框架、输入、组词、拖选、视频、保护、连字、设置页、存储竞态及安装包加载。

性能工具扩展为 38 类独立场景，新增静态属性/转义字体规则、纯布局内联更新、静态条件下反复菜单及强制站点原生连字场景。普通替换和完整 Apple UI Mix 模式均比较无扩展、改动前和改动后，检查最终标记及保护状态。

耗时包含模拟页面及测量钩子开销；主线程任务包含解析、脚本、样式和布局，脚本指标为 CDP ScriptDuration。高频匹配/遍历计数与低干扰计时分开执行，完整样本及范围保存于对应 JSON。

全部 38 类场景的调用量检查共 228 个样本；关闭高频匹配/遍历钩子的计时每组交替顺序重复 3 次，共 684 个样本。两份报告各覆盖 76 个模式/场景组合，均无页面脚本错误，改动后源码摘要与最终文件一致。

## 重复测量结果

以下为 3 次测量的中位数，单位为 ms。

| 场景 | 指标 | 普通替换，前 → 后 | 完整 CSS，前 → 后 |
|---|---|---:|---:|
| 2500 段历史文字、静态属性条件及 40 次菜单创建/销毁 | 主线程 | 932.82 → 96.35 | 2439.97 → 107.06 |
| 同一菜单场景 | 脚本 | 168.37 → 6.42 | 187.60 → 6.71 |
| 同一菜单场景 | 样式重算 | 311.55 → 6.39 | 1524.59 → 6.91 |
| 300 个布局节点的 3600 次内联更新 | 脚本 | 21.36 → 11.66 | 20.33 → 11.51 |
| 强制站点、原生连字、关闭图标保护及 2000 个新元素 | 主线程 | 56.68 → 57.84 | 127.77 → 45.06 |
| 6000 个元素的静态属性及转义字体条件首次加载 | 主线程 | 137.52 → 148.56 | 409.77 → 341.98 |

完整 CSS 模式的菜单场景，主线程耗时范围为 2414.64～2459.97 → 102.87～108.82 ms；字体读取为 92521 → 1 次，样式表停用为 124 → 2 次，长任务中位数为 8 → 0。字体读取下降来自省去菜单销毁时的整页重检。新版在菜单存在期间完成标记，本用例有 80 次标记写入；旧版在节点移除前没有完成这些标记。

纯布局更新的新增回归用例中，800 次变化的临时解析元素创建为 800 → 0 次。强制站点的快捷路径仅用于表中完整 CSS 的指定配置，读取为 2000 → 0 次，样式重算为 85.93 → 4.10 ms；普通替换仍保存原样式，以保护已替换祖先下的代码及图形。

静态属性/转义条件的普通替换冷启动主线程增加 11.04 ms，后续菜单交互则减少整页扫描。完整 CSS 冷启动的读取为 10000 → 3 次，样式重算为 63.99 → 37.37 ms。采样次数和总耗时分别列出，冷启动与重复交互使用不同的测量场景。

## 冷启动补测

800 条通用标签/类名前缀规则的完整 CSS 冷启动，首次 3 次测量的主线程范围为 244.44～260.22 → 245.74～334.88 ms，包含明显的布局时间波动。追加独立浏览器中交替顺序的 5 次补测，中位数为主线程 232.12 → 240.92 ms、脚本 8.12 → 8.46 ms、布局 180.42 → 185.53 ms；主线程范围为 228.22～251.00 → 231.59～242.38 ms。两版均读取 800 次、停用样式表 1 次。

本轮主要收益位于重复交互及指定强制配置，冷启动仍有额外开销。新增补测共 15 个样本，全部测量合计 927 个样本，原始结果与补测分别保存。
