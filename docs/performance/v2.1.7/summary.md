# 字体变量识别修复记录

本轮修复中文、转义和大小写敏感的字体变量名，补齐 var() 函数名称、注释、嵌套回退及内联新增引用的处理。纯 CSS 状态变化的事件触发仍按独立事项保留。

回归使用真实 Chromium 151.0.7922.34；完整测试共 122 项通过。新增测试先复现旧版中文变量更新超时，再验证普通替换和自定义 CSS 的往返切换、CSSOM 保留的转义写法、循环依赖及无关变量零采样。

性能比较基线为 v2.1.6，四个场景、两种模式、每组重复三次，共 72 个样本，全部运行错误为空。关闭高频选择器与遍历计数钩子；耗时包含本地模拟页面及其测量钩子。
