保护与排版规则

避免替换破坏代码和图标，并优化连字与间距排版。

替换名单

每行一个字体族。只有元素的首选字体命中名单时才会替换。

0 个字体族

默认仅包含常见西文与简中系统/UI 字体；可能用于视觉设计的 WebFont 不在默认名单中。

站点特殊规则

对指定站点选择特殊行为：强制替换，或关闭扩展的一切覆盖以便查看网站原生字体设置。

暂无站点特殊规则
点击上方「添加站点」可为特定域名配置强制替换或关闭覆盖。

域名支持主域名与子域名，例如 chatgpt.com、*.example.com；字体留空则使用全局替换字体。代码与图标保护规则仍然生效。

自定义 CSS

向页面注入自定义样式，可用于 @font-face、字体栈或全局排版；跟随全局启用开关。

Apple UI Mix.css

自定义 CSS 始终注入在扩展自身样式之后：与替换字体、标准连字、Auto Spacing 等扩展规则冲突时，以自定义 CSS 为准；留空则不注入。

工作方式
1

扩展逐个检查元素计算后的 font-family，不对整个页面强制指定同一个字体。

2

只有第一个字体族命中名单时才会替换；动态页面会继续检查新增内容。

3

edge://、chrome://、扩展商店等浏览器受保护页面无法注入普通扩展。

4

自定义 CSS 在扩展样式之后注入，与替换字体、连字、Auto Spacing 等扩展规则冲突时以自定义 CSS 为准。
